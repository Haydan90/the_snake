# the_snake

# Игра «Змейка» (Snake Game)

Классическая аркадная игра «Змейка», написанная на языке Python с использованием библиотеки **Pygame**. Проект разработан с применением принципов объектно-ориентированного программирования (ООП).

## 🚀 Особенности проекта
* **ООП Архитектура:** Логика игры разделена на классы: базовый класс `GameObject`, а также унаследованные от него `Snake` (Змейка) и `Apple` (Яблоко).
* **Бесконечное поле:** При достижении края экрана змейка плавно появляется с противоположной стороны.
* **Защита от самопересечения:** Игра автоматически перезапускается, если змейка врезается в собственный хвост.
* **Умный спавн еды:** Новое яблоко никогда не появится внутри тела змейки.

## 🛠 Технологии
* Python 3
* Pygame

## 🎮 Управление
Для управления змейкой используйте стрелочки на клавиатуре:
* ⬆️ **Стрелка вверх** — движение вверх
* ⬇️ **Стрелка вниз** — движение вниз
* ⬅️ **Стрелка влево** — движение влево
* ➡️ **Стрелка вправо** — движение вправо

*Примечание: змейка не может развернуться на 180 градусов в противоположную сторону одним нажатием.*

## 💻 Инструкция по запуску

### 1. Клонируйте репозиторий
```bash
git clone https://github.com
cd the_snake
```

### 2. Установите зависимости
Для работы игры необходима библиотека `Pygame`. Установите её через pip:
```bash
pip install pygame
```

### 3. Запустите игру
Запустите основной файл скрипта (замените `main.py` на реальное имя вашего файла, если оно другое):
```bash
python main.py
```
